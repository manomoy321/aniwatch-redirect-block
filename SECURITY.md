# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within FocusGuard, please report it responsibly:

1. **Do not disclose the vulnerability publicly** in a public issue or forum.
2. Please open a [GitHub Security Advisory](https://github.com/manomoy321/aniwatch-redirect-block/security/advisories/new) or contact the maintainers directly via GitHub.
3. Include detailed steps to reproduce the issue, along with affected versions and browser environments.

Maintainers will review and issue a fix promptly.
